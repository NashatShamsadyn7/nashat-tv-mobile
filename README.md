# 📺 Nashat TV

**Your Premium Kurdish Live TV Streaming App**

![Android](https://img.shields.io/badge/Platform-Android-green?logo=android)
![Min SDK](https://img.shields.io/badge/Min%20SDK-23-blue)
![Firebase](https://img.shields.io/badge/Backend-Firebase-orange?logo=firebase)

Nashat TV is a modern, premium live TV streaming application for Kurdish channels. Watch your favorite Kurdish TV channels anytime, anywhere with crystal-clear quality.

## ✨ Features

- 📡 **60+ Kurdish Channels** — News, entertainment, sports, kids, music, and more
- 🔍 **Smart Search** — Find channels instantly with text or voice search
- ⭐ **Favorites** — Save your favorite channels for quick access
- 🎬 **Premium Video Player** — Full-featured player with gesture controls
  - Swipe for brightness/volume
  - Double-tap to seek
  - Picture-in-Picture mode
  - Playback speed control
  - Audio track & subtitle selection
- 🌙 **Dark Mode** — Beautiful dark theme for comfortable viewing
- 🌍 **Multi-language** — Kurdish (Soranî), Arabic, and English
- 📱 **Responsive Design** — Works on phones, tablets, and Android TV

## 🛠 Tech Stack

- **Language:** Java
- **UI:** Material Design 3 (Material You)
- **Video Player:** ExoPlayer
- **Backend:** Firebase Realtime Database
- **Image Loading:** Glide

## 🚀 Getting Started

### Prerequisites
- Android Studio (latest)
- JDK 11+
- Android SDK 35

### Build
```bash
git clone https://github.com/YOUR_USERNAME/NashatTV.git
cd NashatTV
./gradlew assembleDebug
```
